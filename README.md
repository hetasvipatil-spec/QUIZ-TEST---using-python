# 🎯 Quiz - test (Python)

A beginner-friendly Python quiz application that tests general knowledge through multiple-choice questions.

## Features
- 5 GK questions with 4 options each.
- Automatic answer checking.
- 100 points for every correct answer.
- Displays the final score out of 500.

## Concepts Used
- Python Dictionaries & Nested Dictionaries
- Lists
- For Loops
- Conditional Statements
- User Input

## How to Run
```bash
python kbc.py
```
